## ✨ 核心改进内容

### 第一阶段：UML 语义验证与基础增强

#### 1. UML 语义验证器 🎯
**影响**: 革命性改进 - 从无到有的质量保证系统

实现了 18 条 UML 验证规则，覆盖 5 种图类型：

**用例图验证 (4 条)**
```typescript
✅ include/extend 只能在用例之间
✅ Actor 间应使用泛化而非关联
✅ 用例间应使用 include/extend
✅ 孤立用例检测
```

**类图验证 (5 条)**
```typescript
✅ 继承环检测（DFS 算法）
✅ 双向组合/聚合检测
✅ 自组合/自聚合检测
✅ 实现关系应指向接口
```

**时序图验证 (4 条)**
```typescript
✅ 消息必须在参与者之间
✅ 激活条引用的消息必须存在
✅ 组合片段引用验证
✅ 创建消息应是目标的第一条消息
```

**状态图验证 (4 条)**
```typescript
✅ 初始状态只能有一个
✅ 初始状态不能有入边
✅ 终止状态不能有出边
✅ 不可达状态检测（BFS 算法）
```

**组件图验证 (1 条)**
```typescript
✅ 循环依赖检测（DFS 算法）
```

#### 2. Actor 泛化支持 🔗
**影响**: 用例图功能完整性提升

- ✅ 新增 `generalization` 关系类型
- ✅ 渲染为空心三角箭头（符合 UML 标准）
- ✅ 示例更新：Admin → User 继承关系

**使用示例**:
```typescript
{
  source: 'actor.admin',
  target: 'actor.user',
  type: 'generalization'  // Admin 继承 User
}
```

#### 3. 时序图消息类型渲染 🎨
**影响**: 时序图专业性大幅提升

实现 5 种消息类型的视觉区分：

| 消息类型 | 视觉样式 | 颜色 | 使用场景 |
|---------|---------|------|---------|
| **同步调用** | 实心箭头 | 黑色 | 默认方法调用 |
| **异步调用** | 开放箭头 | 黑色 | 异步消息 |
| **返回消息** | 虚线 + 开放箭头 | 灰色 | 方法返回值 |
| **创建消息** | 虚线 + 开放箭头 | 绿色 | 对象创建 |
| **销毁消息** | 叉号 | 红色 | 对象销毁 |

### 第二阶段：UML 视觉样式增强

#### 4. 类图静态/抽象样式 📝
**影响**: 类图符合 UML 2.5 规范

**静态成员 - 下划线**
```
+ PI: double                    [普通]
+ PI: double                    [静态 - 下划线]
  ‾‾
+ getShapeCount(): int          [静态方法 - 下划线]
  ‾‾‾‾‾‾‾‾‾‾‾‾‾‾
```

**抽象方法 - 斜体**
```
+ getArea(): double             [普通方法]
+ getArea(): double             [抽象方法 - 斜体]
  (斜体渲染)
```

**抽象类/接口名 - 斜体**
```
Shape                           [普通类]
Shape                           [抽象类 - 斜体]
(斜体渲染)

<<interface>>
Drawable                        [接口名 - 斜体]
(斜体渲染)
```

#### 5. 状态图初始/终止状态符号 ⚫⊙
**影响**: 状态图符合 UML 标准

- ✅ **初始状态**: 实心小圆点 ⚫ (深色填充)
- ✅ **终止状态**: 实心圆 ⊙ (深色填充，稍大)
- ✅ 清晰的视觉区分

**改进对比**:
```
改进前：
[Ellipse] → [State] → [Ellipse]
  (普通椭圆)           (普通椭圆)

改进后：
    ⚫  → [State] → ⊙
(实心圆点)          (实心圆)
```

## 💻 使用方法

### 生成带验证的专业 UML 图

#### 用例图（Actor 泛化）
```bash
npm run generate "用例图：管理员继承普通用户，管理员可以管理系统，用户可以浏览和租借工具"
```

**输出**:
- `output/generated-diagram.drawio` - 可编辑文件
- `output/generated-diagram.svg` - SVG 预览
- 控制台显示验证警告（如果有）

#### 类图（静态/抽象样式）
```bash
npm run generate "类图：抽象类 Vehicle 有抽象方法 start 和静态方法 getCount，Car 和 Bike 继承 Vehicle"
```

**特点**:
- `start()` 显示为斜体（抽象方法）
- `getCount()` 显示为下划线（静态方法）
- `Vehicle` 类名显示为斜体（抽象类）

#### 时序图（消息类型）
```bash
npm run generate "时序图：Client 调用 Service 的 getData，Service 创建 Database 连接，Database 返回结果"
```

**特点**:
- 同步调用：实心箭头
- 返回消息：虚线
- 创建消息：绿色虚线

#### 状态图（初始/终止符号）
```bash
npm run generate "状态图：从初始状态到 Idle，transition 到 Running，条件判断后到 Paused 或 Stopped，最后到终止状态"
```

**特点**:
- 初始状态：⚫ 实心圆点
- 终止状态：⊙ 实心圆

### 3. 可扩展架构
新增 UML 规则只需：
```typescript
// 1. 在 uml-rules.ts 添加函数
function validateNewRule(diagram: Diagram): string[] {
  // 验证逻辑
}

// 2. 在主函数调用
export function validateUmlSemantics(diagram: Diagram): string[] {
  // ...
  if (diagram.type === 'new-type') {
    warnings.push(...validateNewRule(diagram));
  }
  // ...
}
```

### 4. 清晰的责任分离
```
模型层 (types.ts)       → 定义数据结构
验证层 (validate/)      → 检查语义和布局
布局层 (layout/elk.ts)  → 计算节点位置
渲染层 (render/)        → 生成 Draw.io XML
```
