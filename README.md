### Chen ER 自然语言格式

Chen ER 的 `--chain` 提供可预测的三段式中文解析（实体 / 某实体属性 / 联系 + 基数），主键下划线、多值双椭圆、派生虚线椭圆，无法可靠理解的文本直接拒绝而不是猜。完整语法与示例：**[docs/CHEN-ER-SYNTAX.md](docs/CHEN-ER-SYNTAX.md)**。
